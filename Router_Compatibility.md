# Совместимость роутеров и провайдеров Казахстана

Статус отражает именно код LANControl KZ, а не наличие функции в самом роутере.

| Провайдер / бренд | Поддержка в приложении | Примечание |
|---|---|---|
| Beeline Kazakhstan | Профиль + веб-панель | Автоматический API зависит от модели CPE и прошивки; без модели не заявляется. |
| Казахтелеком | Профиль + веб-панель | Встречаются разные ONT/роутеры и операторские прошивки. |
| Tele2 / Altel | Профиль + веб-панель | Мобильные CPE/роутеры зависят от модели. |
| AlmaTV | Профиль + веб-панель | Модель определяется на стороне абонента. |
| Transtelecom | Профиль + веб-панель | Универсальный API отсутствует. |
| Freedom Telecom | Профиль + веб-панель | Совместимость зависит от установленного роутера. |
| Keenetic / Netcraze | Нативный RCI | Проверка версии, получение доступных списков клиентов, блокировка/разблокировка с read-back, назначение существующего расписания. |
| Huawei / OptiXstar | Веб-панель | Родительский контроль существует у некоторых CPE; управление производится в интерфейсе роутера. |
| TP-Link | Веб-панель | Access Control документирован для ряда моделей; единый публичный API для данного приложения не подтверждён. |
| ZTE, Nokia, FiberHome, Sercomm, Sagemcom | Веб-панель | Открытие локальной страницы; API не выдумывается. |
| ASUS, MikroTik, Xiaomi, D-Link, Tenda, Mercusys, Netis | Веб-панель | Возможности зависят от прошивки/модели. |
| Ubiquiti, Zyxel, Cudy, Totolink, Linksys, H3C, Ruijie | Веб-панель | Возможности зависят от прошивки/модели. |

## Проверенные технические основания

- Apple требует `NSLocalNetworkUsageDescription` для локальных TCP/UDP/Bonjour-обращений; пользователь контролирует системный доступ к локальной сети.
- Keenetic публикует HTTP API RCI. В командном справочнике описаны правила host access `deny`/`permit` и назначение расписания. Приложение читает результат обратно, чтобы не считать неответившую команду успешной.
- Huawei Kazakhstan описывает родительский контроль на CPE через AI Life или веб-страницу управления (для поддерживаемых моделей).
- TP-Link описывает Access Control с Deny List/Allow List в веб-интерфейсе для поддерживаемых моделей.

Примечание: у некоторых моделей Keenetic доступ к RCI должен быть разрешён для используемого пользователя. Не открывай административный RCI наружу в интернет.
