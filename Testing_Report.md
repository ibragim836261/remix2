# Отчёт проверки проекта

Дата сборки архива: 2026-11-24

## Выполнено в этой среде

- Проверено наличие Swift-файлов, Xcode project, shared scheme, Info.plist, workflow и скрипта упаковки.
- Проверен XML-синтаксис Info.plist и Xcode scheme.
- Проверены обязательные строки конфиденциальности локальной сети.
- Проверено, что в проекте нет сетевого multicast entitlement, фоновых режимов и лишних системных разрешений.
- Проверено, что ZIP содержит исходники, документацию и CI workflow.

## Не выполнено / требуется реальное устройство

- Нативная сборка Xcode не выполнялась: текущая среда Linux, `xcodebuild` и iOS SDK недоступны.
- Не выполнены запуск на iPhone, тесты физического Wi‑Fi, проверка HTTP Digest на разных версиях KeeneticOS и подтверждение команд на реальном роутере.
- Не создан подписанный IPA и не проверена установка через SideStore.
- Совместимость с Beeline Kazakhstan и другими провайдерами нельзя подтвердить без точной модели и прошивки абонентского роутера.

**Статус:** исходный Xcode-проект сформирован; бинарная сборка и аппаратное тестирование ещё не подтверждены. Это не готовый проверенный релиз.


## Изменения v2
- Добавлено поле полного URL роутера в настройках; схема http/https обрабатывается отдельно.
- Встроенный WKWebView получил собственную адресную строку и кнопку перехода.
- Добавлено ручное поле MAC в чёрном списке. Для Keenetic используется RCI; для прочих моделей после ввода MAC открывается встроенная панель, где действие подтверждается самим роутером.
- Проверена целостность ZIP. Сборка Xcode/IPA не выполнялась: среда Linux не содержит Xcode и сертификата подписи.
